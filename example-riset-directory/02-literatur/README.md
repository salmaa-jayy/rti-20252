# 02-literatur

Kumpulan referensi & paper terkait untuk mendukung Tinjauan Pustaka.

## Topik referensi yang relevan

- Keamanan akun media sosial Instagram (kesadaran & perilaku pengguna)
- Autentikasi dua faktor (2FA) — adopsi dan hambatan
- Technology Acceptance Model (TAM) dan UTAUT sebagai kerangka teori
- Kesadaran keamanan informasi di kalangan mahasiswa Indonesia
- Metodologi survei Likert dan analisis korelasi Spearman
